# Детский развивающий центр — индивидуальный проект № 22

Веб-приложение для каталога кружков, профилей детей, записи в учебные группы, просмотра расписания и учёта абонементов.

## Стек

- Python 3.11+
- Django 5.2
- SQLite
- HTML, CSS, JavaScript
- Django ORM и встроенная система аутентификации

## Запуск в Windows

1. Распакуйте архив и откройте папку проекта в терминале.
2. Создайте виртуальное окружение:

   `py -m venv venv`

3. Активируйте его:

   `venv\Scripts\activate`

4. Установите зависимости:

   `pip install -r requirements.txt`

5. Создайте миграции и примените их:

   `py manage.py makemigrations`

   `py manage.py migrate`

6. Загрузите демонстрационные данные:

   `py manage.py seed_demo`

7. Запустите сервер:

   `py manage.py runserver`

8. Откройте `http://127.0.0.1:8000/`.

## Демонстрационные учётные записи

- Администратор: `center_admin` / `CenterAdmin2026!`
- Педагог: `teacher` / `Teacher2026!`

Для проверки кабинета родителя можно зарегистрировать собственную учётную запись. В базе также создаются демонстрационные профили родителей.

## Особое требование варианта 22

При записи ребёнка сервер рассчитывает возраст по дате рождения и сравнивает его с допустимым диапазоном группы. Запись с неподходящим возрастом не создаётся.

Если родитель загружает медицинскую справку на пропущенное занятие, она получает статус «На проверке». После подтверждения администратором система в одной транзакции:
- переводит посещение в статус «Пропуск по справке»;
- возвращает одно занятие на баланс абонемента;
- продлевает срок действия абонемента на количество календарных дней болезни.

## Реализованные разделы

- Регистрация, вход, выход и смена пароля через Django Auth.
- Разделение доступа родителя и администратора.
- Профили детей с добавлением, просмотром, редактированием и удалением.
- Каталог кружков с поиском, фильтрами и сортировкой.
- Запись ребёнка в группу с серверной проверкой возраста и свободных мест.
- Расписание занятий.
- Абонементы и отметки посещаемости.
- Загрузка медицинских справок с проверкой расширения и размера.
- Подтверждение и отклонение справок администратором.
- Сводные показатели и диаграмма посещаемости.
- JSON-представления и обновление блока страницы через fetch.
- Экспорт списка детей в CSV.
- Демонстрационная команда с 30 профилями детей и 32 группами.
- Адаптивная вёрстка для экранов 360, 768, 1024 и 1440 пикселей.

## Почтовые уведомления

По умолчанию используется консольный почтовый бэкенд Django. Письма выводятся в терминал. Для реальной отправки заполните переменные `EMAIL_HOST_USER` и `EMAIL_HOST_PASSWORD`, а также установите `EMAIL_BACKEND` на SMTP-бэкенд в `config/settings.py`.

## Перед публикацией

Сгенерируйте собственный `SECRET_KEY`, задайте `DEBUG=False`, заполните `ALLOWED_HOSTS`, настройте SMTP и используйте HTTPS. Не публикуйте демонстрационные пароли и файл базы данных с тестовыми данными.
